## 적용한 결정

1. QR 메뉴판은 매장 손님용이므로 **네이버 주문의 매장 가격**을 적용합니다. 배달 가격이나 다이닝코드 가격으로 섞어 채우지 않습니다.
2. 네이버 매장 주문에 노출된 **19개 고유 메뉴**를 반영합니다. 새 메뉴/추천 영역의 중복 항목은 한 번만 넣습니다. 다이닝코드나 배달 메뉴에만 있는 된장찌개·한치물회·떡사리는 추가하지 않습니다.
3. 원본의 `메뉴`·`주류` 그룹을 손님이 찾기 쉽도록 **식사류 / 고기류 / 냉면·사이드 / 주류·음료**로 재분류했습니다. 이 네 분류는 웹 메뉴판용 편집 분류입니다.
4. 메뉴당 가격은 하나입니다. 200g·400g, 정식/후식, 비조리는 서로 다른 메뉴로 구분합니다. 냉면의 정식 표기를 밥이나 추가 반찬이 포함된 세트로 해석하지 않습니다.
5. 매장 주문 사진 7개와 배민에 등록되어 네이버에서 확인한 몸국 사진 1개를 사용합니다. 사진 없는 11개 메뉴는 `image_path: null`로 표시하고, 다른 음식이나 방문자 리뷰 사진으로 채우지 않습니다.
6. 설명은 등록된 메뉴명·설명·원산지의 사실만으로 짧게 작성하고 영어·간체·번체로 번역했습니다. 매운갈비찜의 공기밥 별도, 흑돼지주물럭의 흑돼지+오징어, 갈비의 중량과 비조리 조건을 보존합니다. 조리법·전체 재료·맵기 단계·영양·식단 적합성은 추정하지 않습니다.
7. 공개된 원산지의 구체적인 제주산·러시아산·미주산 표기는 메뉴 설명에 보존합니다. 기존 DB 코드로 표현 가능한 소고기/돼지고기/쌀의 국가 정보만 `origin_info`에도 넣습니다. **미주산을 미국산으로 바꾸지 않습니다.** 기존 SQL의 원산지 코드·국가 코드 제약은 변경하지 않았습니다.
8. 매장이 검수한 알레르기 유발 재료 목록은 확인되지 않아 모든 메뉴를 `allergen_review_status: unreviewed`로 두고, 가상의 알레르기 데이터를 제거했습니다. 빈 배열을 알레르기 없음으로 표시하지 않습니다.
9. 네이버의 주문 종료/영업 종료를 음식 품절로 취급하지 않습니다. 이번 자료는 공개 등록 메뉴의 정적 스냅샷이며 가격·품절 실시간 연동은 수행하지 않습니다.
